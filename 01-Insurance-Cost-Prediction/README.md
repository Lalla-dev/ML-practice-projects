# Insurance Cost Prediction

## Objective
Develop a machine learning model to predict insurance costs based on personal health and demographic factors. This project focuses on understanding the relationships between various features and their impact on insurance premiums.

## Dataset
- **File**: `insurance.csv`
- **Records**: Health and insurance data
- **Format**: CSV

## Features Used
- Age
- Sex
- BMI (Body Mass Index)
- Children (number of dependents)
- Smoker status
- Region

## Preprocessing Steps
- Data cleaning and validation
- Exploratory Data Analysis (EDA)
- Handling missing values
- Feature engineering and scaling
- Chi-Square feature selection
- Encoding categorical variables
- Data visualization and correlation analysis

## Models Used
- Linear Regression
- Polynomial Regression
- Ridge/Lasso Regression
- Tree-based models

## Results
- Model performance metrics (R² score, RMSE)
- Feature importance analysis
- Prediction accuracy on test data

## Skills Demonstrated
- **Data Cleaning**: Handling and validating raw data
- **Exploratory Data Analysis (EDA)**: Understanding data distributions and relationships
- **Feature Engineering**: Creating meaningful features from raw data
- **Feature Selection**: Chi-Square method for identifying relevant features
- **Data Visualization**: Using matplotlib, seaborn for insights
- **Libraries**: Pandas, NumPy, Scikit-learn
- **Statistical Analysis**: Correlation and distribution analysis
- **Model Development**: Regression techniques and hyperparameter tuning
